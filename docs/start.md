# 这本手册怎么用

假设你是一个刚下班、孩子刚哄睡的大人，只剩二十分钟。你不会从头读一本教科书，你会先找"我现在卡在哪"。所以这本书按三条路径来写，你从任意一条进来都行。

## 三条路径，任选一条

第一条是**按年龄**。把 0 到 22 岁切成八段，一段一页。每页都回答同样四个问题：这个阶段孩子身上正在发生什么；睡眠、屏幕、运动这三条硬指标是多少；最容易踩的坑是什么；AI 在这个年龄应该扮演什么角色。如果孩子刚上一年级，你就只读第六页，前面的可以完全跳过。

第二条是**按问题**。"他不写作业""她开始在意同学怎么看她""他要用 AI 写作文"——这类问题分散在各章，但入口集中在首页的六张卡上。首页就是检索台。

第三条是**按连播**。底部播放条选"全书"，从这一页开始，它会一页一页念下去。适合通勤、洗碗、跑步、哄睡后那半小时。

## 八段是怎么切的

分段不是为了对表，是为了让你知道**该拿什么标准看这个孩子**。八段的切点都有理由：一岁左右语言开始爆炸，三四岁进入假装游戏和规则意识，六岁进入"我能不能行"的比较期，九到十岁青春期前的身体准备期，十二岁同伴权重上升，十五到十八岁是长时间高压与睡眠不足的正面冲突，十八到二十二岁第一次独自同时管理日程、钱和身体。

这八段的完整列表在 [0→22 岁全景地图](./map/timeline.html)，那里还有一张对照表，把每段的发育主线和硬指标并排放。

## 这本书给每句话标等级

调研阶段我把所有材料分成四级，读者看不到符号，但能看到差别：

- **可核**：一手研究、官方指南或法规原文，写出来就是它本来的样子。
- **需要限定**：二手来源、样本有局限或各口径不一致，正文里会出现"约""据……调查""这是自陈问卷"。这些限定词不是客套，是这句话的重量。
- **流行但证据弱**：只允许出现在 [辟谣那一章](./evidence/red-lines.html)，不会在别的页面被当事实使用。
- **查无实据**：不进这本书。我在写作规范里给它起了个名字叫"红线"，一共十几条，包括几个中文育儿语境里被引用了十年、但我找不到出处的"研究"。

这套规矩的原样记录在 [来源清单与写作规矩](./evidence/sources.html)。

::: tip 一个 15 秒的判断法
看到任何一条育儿结论，先问三件事：**样本多少人、跟的是什么（成绩、行为还是大脑）、后来有没有被别人复现**。三问里有一问答不上来，就先存疑。这本书的每一条都尽量把这三问答全。
:::

## 男孩女孩为什么要分开写

先说清理由，免得被误解成"男女有别所以该分开培养"。

分开写有两个原因。一是**压力来源确实不同**：在可核数据里，男孩更集中的问题是阅读落在底部和友谊网络萎缩，女孩更集中的问题是自我挤压、外在评价和节食行为。这两种"难"需要不同的应对动作。二是**很多建议本身带着性别假设**，混在一起写就分不出哪句有证据、哪句是习惯。

但两性之间的真实差异只有四条，而且量级很小——性别只解释每个基因表达方差的 0.3%。所以三页的顺序是固定的：[先读这页：差异到底有多大](./gender/how-to-read.html)，再看 [男孩](./gender/boys.html) 和 [女孩](./gender/girls.html)。

## AI 时代这一章为什么单独存在

因为它改变了这本书的写法。过去养育建议的隐含前提是"孩子面对的信息来自人和书"，现在多了一个随时应答、听起来很有把握、不带情绪也不累的对象。这件事在三个地方产生了具体问题：学习（AI 当陪练有效、代工则收益消失）、情绪（孩子开始把心里话先给 AI）、以及未来（专业与技能组合的保质期变短）。

中国这边还有一条很少被家长读到的东西：**教育部 2025 年的指南确实给了年龄线**——小学阶段禁止学生独自使用开放式内容生成功能，初中和高中各有各的口子。这部分内容集中在 [AI 时代](./ai/overview.html)，年龄线在 [分阶段陪法](./ai/stages.html)。

## 它做不到什么

不做诊断，不预测你家孩子，不承诺成绩。这三条写在 [首页](./index.html) 最后一节，也写在这里，因为一本讲证据的书最不该做的事，就是假装证据能覆盖到单个家庭的具体处境。

涉及医疗和心理健康的地方，这本书只给"值得去挂号的信号"，不给判断。任何时候你手上的情况比书里写的更糟，以你面前的医生和心理咨询师为准。

## 这一页的三行结论

- **只记一件事**：这本书是查询工具，不是必读文本。按年龄、按问题、按连播，三条路任选。
- **今天就能做**：找到孩子所在的那一页，只看"三行结论"那一节。四分钟。
- **别这么做**：不要拿任何一页去评价别人家的做法。它描述的是分布，不是你家孩子。
