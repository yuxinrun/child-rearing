# 关于本站

## 它想解决的那件具体事

关于养育的信息已经够多了。多到一件新的麻烦出现了：你需要花不少力气去分辨哪句话有研究撑腰、哪句话只是被人转发了三十年没人追问。

我做过一件跟这很相似的事——把一套 AI 架构讲到能给别人复述一遍（那是姊妹站《Super-agent 讲透》）。做法可以复用：把能核的东西摊开，把不确定的标明，把流传很广但站不住的单独隔离出去。这本书就是同一个流程，换了个主题。

所以这本手册有三个特征，都不是为了显得严谨，是为了让你能省时间：

- **每句话尽量带来源**。研究、官方指南、法规三类分开处理，法规只说法规原文里真的写了什么。
- **不确定的地方直接写"不知道"或"各口径矛盾"**。比如儿童性早熟的患病率，中文网络流传的三个"官方"数字相差十倍以上，这本书一个都不用，只给定义和该去挂号的信号。
- **流行但证据弱的说法被集中关押**。它们只出现在 [十三句很流行的话](./evidence/red-lines.html) 那一页，不会在别处被当事实偷偷使用。

## 为什么男孩女孩要分开写

两个理由，都不是"男女有别所以该分开培养"。

第一，**压力来源确实不同**。可核数据里，男孩更集中的问题在阅读能力的底部（国际学生评估项目的阅读差距最大处不在顶尖学生，而在尾部）和友谊网络的萎缩；女孩更集中的问题在自我挤压——外在评价、节食行为、以及"作业超过两小时还自愿再加两小时"的那种认真。这两种难，需要不同的动作。

第二，**很多常见建议本身就带着性别假设**，混在一起写就分不出哪句有证据、哪句是习惯。分开写之后，"被夸大的差异"这一节才有地方放。

同时必须说清量级：2026 年《科学》上的单细胞研究发现，性别只解释每个基因表达方差的 0.3%，而细胞类型解释 51.1%、个体差异解释 3.9%。两性之间的差异真实存在，但小到不足以用来预测你面前这个孩子。三页的顺序因此是固定的：先看量级，再看 [男孩](./gender/boys.html)，最后看 [女孩](./gender/girls.html)。

<div class="mp-quote">这一章的写法是：先把差异缩小到能诚实描述的程度，再把该给的支持给够。前者防止贴标签，后者防止装作没事。</div>

## 为什么要有听书

因为大多数家长真正空出来的整块时间，在通勤路上、在洗碗池前、在孩子睡着后的那半小时。这些场景眼睛不自由，耳朵自由。

技术上它并不复杂：浏览器自带的语音合成接口，把正文切成适合朗读的短句，一句接一句念，念完这一页自动翻到目录里的下一页，并注册系统媒体控制好让锁屏也能操作。代价是必须承认它的短板——机器念的是文字，不是图表。所以这本书定了一条写作规矩：**凡是你应该听到的数字，正文里必须用一句话说一遍**，不许只放在表格中。这条规矩反过来让全书更好读，即使你不听。

具体用法、浏览器差别和快捷键在 [把这本手册当成有声书](./listen.html)。

## 我不做的三件事

**不做诊断。** 发育里程碑、性早熟、抑郁与进食问题，都只有面对孩子的医生能判断。这本书只写"什么信号值得挂号"。涉及心理健康的段落，顺序永远是先给求助出口，再给观点。

**不预测你家孩子。** 所有关于年龄和性别的描述都是分布。同一段文字落在两个孩子身上可能得出相反的判断，因为他们的位置比群体平均值重要得多。

**不承诺结果。** 养育投入和孩子成就之间的相关性，比机构愿意承认的小。有一项发在《婚姻与家庭杂志》上的研究甚至发现，家长陪伴的总时长对六到十二岁孩子的结果几乎没有独立效应。这句话听起来让人泄气，但它是这本书的地基：既然时长不是答案，那就要认真讨论**什么才是**——家里的压力水平、你说出口的那句话、以及你自己还剩多少。

## 一处必须坦白的局限

这本书是一份**二手材料的分级整理**，不是新的研究。科普书是对研究的解读，解读会带偏好；中国语境下的很多调查是自陈问卷，只适合看趋势；几处关键数字（比如青少年使用 AI 陪伴的比例）我没能找到一手来源的完整口径，只能标"据某调查"。达拉斯联储和斯坦福那两篇是 2026 年的工作论文，方向清楚，结论还没有经过多少反驳。这些在 [来源清单与写作规矩](./evidence/sources.html) 里逐条写了。

如果你在书里发现一处被写得比证据更确定，那是我写错了。页面底部有"在 GitHub 上编辑此页"，欢迎把它按回去。

## 品牌与作者

本站由 **鱼心快跑** 出品，设计语言（暖纸底色、深海绿、蓝图虚线、Manrope 加等宽字）沿用了同一套规范。姊妹站：

- 《Super-agent 讲透》——把一套 AI 架构讲到能给同事复述
- 《MCP Patterns》——Agent 工具接口的模式集

## 这一页的三行结论

- **只记一件事**：这本书的价值不在建议多，在于它把"能核的""要限定的""站不住的"分开放。
- **今天就能做**：把孩子那一页里出现的每个数字，都问一遍"这是谁在哪年测量的"。
- **别这么做**：不要把这本书当成对别人家做法的评价标准。它描述分布，不审判个人。
