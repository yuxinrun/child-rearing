# 把这本手册当成有声书

这本书的正文是写给眼睛的，也是写给耳朵的。区别在于眼睛可以跳读，耳朵不行——所以每一页在写作时都遵守了一条额外规矩：**凡是希望你听到的数字，必须在正文里用一句完整的话说过一遍**，不能只塞进表格里。

## 怎么用，三个动作

第一，**按播放**。页面底部那条播放条中间的圆角按钮。浏览器不允许网页自己出声，必须有一次你的点击或触摸作为起点，之后它就能自己走下去。

第二，**把范围切成"全书"**。播放条右侧有三档：本页、本章、全书。选"全书"之后，这一页念完会自动翻到目录里的下一页，重新抓正文、继续念。26 页正文的顺序就是左侧目录的顺序。想停下来，按停止；想只听完这一段，选"本章"。

第三，**换语速**。0.75 到 2 倍。中文语音在 1.25 到 1.5 之间最像"一个说话利索的人"；超过 1.75 之后长句会开始糊。语速和声音会被记住，下次打开还是它。

::: tip 快捷键
`Alt + P` 播放或暂停，`Alt + →` 下一句，`Alt + ←` 上一句。电脑上有麦克风或者正在输入的时候，Alt 组合键可能被系统抢走，那就用屏幕上的按钮。
:::

## 手机上能做什么

锁屏控制是注册进系统的：安卓的 Chrome、Edge，iPhone 的 Safari，锁屏界面通常会出现一条播放控件，可以暂停、继续、跳上一句或下一句。个别系统会在锁屏后限制网页活动，表现为念完当前句子就停——这不是这本书坏了，把浏览器切回前台再按一次播放就行。

手机浏览器的省电策略也可能中断朗读。如果你要走一段很长的路，最稳的做法是：把屏幕亮度调低而不是关闭屏幕，并且别让浏览器进入深度后台。

## 为什么有的浏览器念得像人，有的像导航

声音不是本网站提供的，是你设备上装的语音。所以效果完全取决于浏览器和系统。

- **Edge（电脑）**：可选列表里通常有 "Microsoft Xiaoxiao Online (Natural)" 这类神经语音，是三大浏览器里最像人的。
- **Chrome（电脑与安卓）**：一般是 "Google 普通话（中国大陆）"，稳定、清楚，但没有起伏。
- **Safari（iPhone、Mac）**：用的是系统语音，iOS 17 之后可以在"设置 → 辅助功能 → 朗读内容"里下载增强版中文语音，装完之后这本书会直接用上它。
- **Linux 上的 Firefox**：可能一个语音后端都没装，这时候会念不出声音。

播放条右侧的下拉框默认只列中文语音。想看看系统里还装了什么，点旁边的"全部声音"，列表会放开；再点一次变回"只看中文"。下拉框里只有一项，说明你的设备目前只有一个中文声音可用。

## 哪些内容不会被念出来

表格、图表、代码块会被跳过。原因很实际：把一张七行四列的睡眠表念成"十四到十七、十二到十六、十一到十四"，人听完也记不住。

代替方案是：这些数据组件旁边都配了一段正文，用话说一遍同样的结论。如果你觉得某个组件里的信息值得被念出来，那是页面的写法有问题，可以按页面底部"在 GitHub 上编辑此页"提出来。

::: warning 一句实话
机器朗读解决的是"腾出手和时间"，不解决"读不读得进去"。复杂的部分——比如辟谣那一章为什么某个效应量算小——还是得看文字。听书适合把框架装进脑子，不适合替你完成理解。
:::

## 通勤排期参考

一页正文大约 1200 到 2200 字，1 倍语速下 4 到 7 分钟。播放条会显示"本页约 X 分钟"，念起来之后会改成"本页还剩约 X 分钟"。

按单程 30 分钟算，一周（两个来回）能走完一个阶段加一章的开头。全书听完大约两小时四十分钟——比一部电影的长版稍长一点，比你刷手机的时间短得多。

## 关于隐私

朗读发生在你的设备上或你的浏览器后端里，本网站不上传你的阅读进度，也不记录你听了什么。进度只存在浏览器自己的临时存储里，关掉标签页就没了。

需要留意的是：浏览器自带的"神经语音"往往把文本送到厂商云端合成。这本书的内容本来就是公开文本，无所谓；但**不要**把这套朗读方法拿去念你自己的私密文档。

## 这一页的三行结论

- **只记一件事**：一次点击启动，之后它自己翻页。想一直听到最后，就把范围设成"全书"。
- **今天就能做**：把语速调到 1.25，声音选下拉框第一个带 "Natural" 或"神经"字样的。
- **别这么做**：不要在需要看图表的地方指望听懂。数字都在正文里，但形状在图里。
